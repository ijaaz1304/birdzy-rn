# Environment setup on a new machine

## Quick start

```bash
git clone <repo-url>
cd Shroom-Ai
npm run ci:install

# Option A — copy real env files from another machine (recommended)
scp user@old-machine:/path/to/Shroom-Ai/.env.dev ./
scp user@old-machine:/path/to/Shroom-Ai/.env.prod ./

# Option B — start from templates, then paste secrets
cp .env.dev.example .env.dev
cp .env.prod.example .env.prod
# Edit .env.dev and .env.prod with real keys

# Activate dev or prod config (copies to .env for Metro/babel)
npm run env:dev
# or
npm run env:prod

npm run start:dev
```

## How it works

| File | Purpose |
|------|---------|
| `.env.dev` | Development secrets (gitignored) |
| `.env.prod` | Production secrets (gitignored) |
| `.env` | Active config — generated by `npm run env:dev` or `env:prod` |
| `.env.dev.example` | Safe template committed to git |
| `.env.prod.example` | Safe template committed to git |

Script: `scripts/switch-env.js` copies `.env.dev` or `.env.prod` → `.env`.

## Transfer env from this Mac to another system

**AirDrop / USB / secure chat** — copy these two files:

- `.env.dev`
- `.env.prod`

**SCP from this machine:**

```bash
# Run on the NEW machine (replace USER and OLD_HOST)
scp USER@OLD_HOST:~/TrackzioApps/Shroom-Ai/.env.dev .
scp USER@OLD_HOST:~/TrackzioApps/Shroom-Ai/.env.prod .
```

**Do not commit real `.env.dev` / `.env.prod` to GitHub** — they contain API keys, `APP_SHARED_SECRET`, and geocoding keys. Use private transfer only.

## Keys you need if filling manually

| Variable | Where to get it |
|----------|-----------------|
| `GOOGLE_WEB_CLIENT_ID` | Google Cloud Console → OAuth 2.0 Client ID (Web) |
| `GOOGLE_MAPS_API_KEY` | Google Cloud Console → Credentials (Static Maps API enabled) |
| `GEOCODING_API_KEY` | [geocode.maps.co](https://geocode.maps.co) dashboard |
| `APP_SHARED_SECRET` | Team / backend config |
| `RATING_FEEDBACK_API` | AWS Lambda URL for feedback endpoint |

See also: [LOCATION_INTEGRATION.md](./LOCATION_INTEGRATION.md) for geocoding usage.
